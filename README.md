# 智心一梦助手

一个 `一键启动、免安装、纯客户端` 的 Windows 个人助手。

它不只是一个聊天框，而是一个由 **宠物系统**、**员工系统**、**记忆系统** 组成的小型 AI 工作台。你可以把它理解成：在自己的电脑里养一只宠物，同时拥有一支会协作、会成长、能帮你做事的数字团队。

- 介绍网站：[智心一梦助手](https://studio.ai-nous.com/)
- 下载地址：[GitHub Releases](https://github.com/Pankitgg/open-ai-tool/releases)
- 相关文章：[仿 openclaw 调度，手搓一个免安装的 windows 个人助手，我管他叫智心一梦](https://blog.ai-nous.com/posts/%E4%BB%BFopenclaw%E8%B0%83%E5%BA%A6%E6%89%8B%E6%90%93%E4%B8%80%E4%B8%AAwindows%E4%B8%AA%E4%BA%BA%E5%8A%A9%E6%89%8B%E6%88%91%E5%8F%AB%E4%BB%96%E6%99%BA%E5%BF%83%E4%B8%80%E6%A2%A6/)

## 项目简介

一直想做一个真正能提效的工具，像一个团队一样帮我思考、讨论和解决问题。`openclaw` 给了我很多启发，但它的体量和复杂度也让我一直在想：能不能用更轻、更直接的方式，纯手工搭一个属于自己的多 agent 调度系统？

另一个执念来自小时候玩的 QQ 宠物。那种陪伴感、成长感和互动感一直很有吸引力。到了 AI 时代，我更想把这种体验和生产力结合起来，做一个既能陪伴、又能干活，而且 **所有数据都留在用户本地** 的桌面助手。

所以这个项目从一开始就很明确：

> **核心构成**
>
> **宠物系统** + **员工系统** + **记忆系统**

拥有它，你既拥有了一个可以持续成长的 `宠物`，也拥有了一个能一起工作的 `专业团队`。

## 核心特点

- **纯客户端**：无需部署服务端，数据默认存储在本地。
- **员工协作**：可创建多个数字员工，在会议室中协同讨论任务。
- **记忆系统**：员工拥有自己的记忆和对话上下文，能逐步形成风格与经验。
- **工具扩展**：支持生成工具并分配给员工，让助手不仅能说，还能做。
- **宠物模式**：提供更轻松、更有陪伴感的桌面交互体验。

## 快速开始

### 下载安装

可通过以下任一方式获取：

- 官网：[智心一梦助手](https://studio.ai-nous.com/)
- 发布页：[GitHub Releases](https://github.com/Pankitgg/open-ai-tool/releases)

### 首次配置模型

先进入设置页，添加模型配置并设置默认模型：

![设置](./docs/images/zxym-4.png)

你需要填写模型的 `API Key` 和 `Base URL`。如果你还没有模型，可以参考以下平台：

- [智谱](https://www.bigmodel.cn/glm-coding?ic=W2CYSKAEOC)
- [阿里云](https://www.aliyun.com/benefit/ai/aistar?clubBiz=subTask..12415419..10263..)
- [DeepSeek](https://platform.deepseek.com/usage)

> 推荐购买按次收费的 coding plan，整体更省钱。**免费模型的性能较差，可能会明显影响体验。**

示例配置如下：

**智谱**

![智谱模型配置](./docs/images/zxym-3.png)

**DeepSeek**

![deepseek 模型配置](./docs/images/zxym-5.png)

> **注意**
>
> 1. 模型配置通常只需要添加一次，后续可在设置中切换。
> 2. `API Key` 和 `Base URL` 属于你的个人配置，请不要分享给他人。
> 3. 如果模型始终没有回复，优先检查模型配置是否填写正确。

### 创建员工

进入员工创建页面后，可以通过 AI 自动生成员工设定。输入你想要的员工描述，点击生成即可。

例如：

```text
智心一梦是一个很有才华的员工，他会帮助我完成一些任务
```

或者：

```text
石头人是一个杠精，他会无情地干掉 ADC
```

![添加员工](./docs/images/zxym-6.png)

![添加员工](./docs/images/zxym-7.png)

重复这个过程即可添加多个员工。

### 生成工具

当基础对话能力可用后，你还可以进一步配置技能或插件，让助手从“会说”升级到“能做”。

进入工具箱，输入你想要的工具描述后点击生成。例如：

```text
一个用来展示条目信息的组件
```

左侧可以切换生成样式：

![生成工具样式](./docs/images/zxym-13.png)

![生成工具](./docs/images/zxym-12.png)

等待一段时间后即可生成工具。

> **注意**
>
> 生成工具需要一定时间，具体取决于模型性能。生成过程不会被打断，后续也仍然可以在工具箱页面继续修改。

生成完成后，可以继续通过 AI 优化或手动调整：

![生成工具](./docs/images/zxym-16.png)

点击安装后，可以在下方调试区进行模式切换、数据调试以及 AI 辅助修改：

![生成工具](./docs/images/zxym-17.png)

![生成工具](./docs/images/zxym-18.png)

生成好的工具可以在多个位置直接使用。首页可以直接点击工具，右键可隐藏。

### 将工具配置给员工

生成好的工具还可以分配给员工，让员工在会议室中主动调用。

1. 进入数字员工界面。
2. 点击技能库，新增技能。
3. 技能类型选择 `tool`。
4. 在工具列表中选择已经配置好的工具。
5. 再进入具体员工页面，在技能下拉内容中添加所需技能。

![工具配置给员工](./docs/images/zxym-19.png)

![工具配置给员工](./docs/images/zxym-20.png)

![工具配置给员工](./docs/images/zxym-21.png)

> **注意**
>
> 1. 技能或工具配置给员工后，员工才可以在会议室中使用。
> 2. 目前工具的触发仍然依赖员工自行判断，暂时没有自动触发机制。
> 3. 系统默认已经内置了一些技能。

## 路线图

- 增加 **小鱼干**，作为和宠物交互的代币，丰富宠物玩法。
- 继续完善宠物特征、互动方式以及整体陪伴体验。
- 建设插件市场，让用户可以上架游戏或其他插件，并与宠物产生更多联动。
- 增加会议室和员工配置的高质量样例，沉淀真正好用的实践模板。
- 持续优化记忆系统，覆盖更多触发场景，提升总结与清理机制的稳定性。

还有很多有趣的想法，后面会慢慢补进来。
